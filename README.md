# async-job-queue

Асинхронная очередь задач и пул воркеров на Python с использованием `asyncio`.

## Возможности
- Неблокирующая очередь на базе `asyncio.Queue`.
- Автоматические повторные попытки с экспоненциальной задержкой (Exponential Backoff).
- Изоляция необработанных задач в Dead Letter Queue (DLQ).
- Наглядный табличный вывод статусов выполнения.

## Запуск

```bash
pip install rich
python main.py
```
