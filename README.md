# async-job-queue

Легковесный воркер и очередь фоновых задач на чистом `asyncio` без внешних брокеров сообщений вроде Celery или Redis.

## Возможности

- Неблокирующая очередь на базе `asyncio.Queue` с пулом воркеров.
- Повторные попытки при сбоях с экспоненциальной задержкой (Exponential Backoff).
- Очередь недоставленных сообщений (Dead Letter Queue, DLQ) для задач, исчерпавших лимит попыток.
- Вывод статусов задач и метрик в терминал через `rich`.

## Запуск

```bash
pip install rich
python main.py
```
